# REPAC Tool Ideas

These are nascent ideas for family- and community-facing tools. They came from the [Shipyard pep rally brainstorm](https://github.com/riverside-pirates/shipyard/blob/main/ideas/2026-10-11-pep-rally-brainstorm.md) on October 11, 2026. None of them are bounties yet.

**Ground rules:** No logins for families. No family contact data in the repo. Printed and translated copies count.

## FamilyLink Translate, `medium`
- **Pitched by:** Dana (REPAC parent).
- **Why:** Every family should get the same news, in their own language, on the same day.
- **What it'd take:** Translated versions of key pages, like events, fundraising, and freshman info, in the top home languages. Start with one page and one language.
- **First question:** Which languages do Riverside families actually speak at home?

## ParentPing Newsletter, `medium`
- **Pitched by:** Mr. B. Built on by Dana.
- **Why:** Stop retyping the same updates. Generate the newsletter from what's already on the site.
- **What it'd take:** A page that collects recent events and announcements into a **printable** layout, so families without email still get a paper copy. Dana's version adds text and print.
- **Caution:** Don't collect family phone numbers or emails in this repo.

## Volunteer Sign-Up, `medium`
- **Pitched by:** Dana.
- **Why:** One place to see open shifts and sign up in two taps, instead of a long group text.
- **What it'd take:** A list of open shifts on the site, plus whatever sign-up tool REPAC already uses (Wix forms?). No GitHub account required for parents.

## Lab Fund Tracker, `easy`
- **Pitched by:** Dana.
- **Why:** Show donors where the money goes.
- **What it'd take:** A goal and progress bar on `fundraising.html`, driven by a small JSON file that a REPAC officer updates.

## Build Showcase Board, `medium`
- **Pitched by:** Dana.
- **Why:** Let families see what engineering students build, explained in plain language.
- **What it'd take:** A gallery page of student projects with photos and short write-ups.
- **Caution:** Use first names or pseudonyms only, and get photo consent first. Check district media-release rules.
